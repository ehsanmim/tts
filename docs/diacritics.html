Persian Diacritization — Benchmark

Text-to-text: unvoweled Persian input → output with diacritics / pronunciation annotation  · 

State of the art: Unlike Arabic (CATT, Sadeed, Fine-Tashkeel), dedicated full-diacritization for Persian does not yet exist as an open-source tool. Persian writing almost never uses short vowels outside dictionaries and children's books, so labeled training data is scarce. The two tools below cover what is currently available: (1) Ezafe detection adds the single most common diacritic — the linking /-e/; (2) KaamelDict provides word-level phoneme pronunciation from a 116k-word dictionary.
ِ = kasra added by Ezafe detector phoneme = KaamelDict G2P annotation (Latin, shown under word)
dadmatools — Ezafe (kasreh) Neural Persian
Detects Ezafe constructions (e.g. کتابِ من) and adds kasra ِ to the preceding noun/adjective. Ezafe is the linking vowel /-e/ that connects nouns to their modifiers in Persian — the single most common diacritic omission. Only kasra is added; all other short vowels remain unmarked.
