Persian Diacritization — Benchmark

Text-to-text: unvoweled Persian → output with diacritics / pronunciation annotation  · 

State of the art: Unlike Arabic (CATT, Sadeed, Fine-Tashkeel), full harakat restoration for Persian does not yet exist as an open-source tool. The tools here cover Ezafe — the linking vowel /-e/ that is Persian writing's single most impactful omission for TTS. abreza/persian-ezafe-albert (F1 98.7%) is the current best option; dadmatools' kasreh has lower recall. KaamelDict adds word-level G2P phoneme pronunciation.
ِ = kasra/Ezafe added phoneme = KaamelDict G2P (Latin, shown under word)
